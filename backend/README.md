# ServeNest Backend

This directory contains the backend code for the ServeNest application, which provides household services on demand. The backend is responsible for handling user requests, managing service providers, processing payments, and ensuring secure and efficient communication between users and professionals.

## Technologies Used
- **Node.js**: Server-side JavaScript runtime.
- **Express.js**: Web framework for building RESTful APIs.
- **MongoDB**: NoSQL database for storing user and service data.
- **Mongoose**: ODM for MongoDB to manage data relationships.
- **JWT**: JSON Web Tokens for secure authentication.
- **Stripe**: Payment processing platform for handling secure transactions.
